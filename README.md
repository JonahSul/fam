# FAM - Fellowship Access Montana

AI-enabled services for NA fellowship members.

## Components

### 🔧 [mcp-tool](./mcp-tool/) - MCP Server
- BMLT integration for NA meeting searches
- Production ready

### 📱 [fam-app](./fam-app/) - React Native App  
- Firebase integration with chat UI
- Genkit AI agent integration

### 🎯 [mobile_app/montanagent](./mobile_app/montanagent/) - Flutter App
- Comprehensive glass morphism UI
- Authentication and chat features
- Agent mode capabilities

## Quick Start

1. **Prerequisites**: Node.js 20+, Flutter 3.22+, Firebase CLI
2. **Setup**: Clone repo, install dependencies, configure API keys
3. **Run**: See individual component READMEs for specific instructions

## API Keys Required

- Firebase project with Authentication, Firestore, Functions
- Google AI (Gemini) API key
- BMLT API access

See [QUICK_START.md](./QUICK_START.md) for detailed setup instructions.
